Fairway Investing — redesign mockups

Visual reference for the implementation spec (fairway-claude-code-spec.md). Each screen is shown desktop and mobile in the real brand palette (page #1a1916, cards #22201d, rust #bd7a70, cream #f7f3ed). This shows the intended look; the spec is the source of truth for behaviour. Open this file in a browser to view.

3 · Upcoming dates (Item 8)

Pick a client once, add several milestones in one go, save together. Urgency colours are monotonic (closer = hotter: red <7d, amber 7–14d, green 14d+). Tick milestones off; archive a client into "Completed clients" when all are met.
